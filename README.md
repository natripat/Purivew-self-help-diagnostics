# Purview Self-Help Diagnostics — Review & Testing Portal

🔗 **Live Site:** [https://natripat.github.io/Purivew-self-help-diagnostics/](https://natripat.github.io/Purivew-self-help-diagnostics/)

## About

This portal is used to test, track, and provide feedback on Microsoft Purview Self-Help Diagnostics. It supports the documentation review project for improving customer experience with self-help diagnostic tools.

## Features

### 📋 Dashboard (`index.html`)
- **Test Tracker** — Track testing of all 19 diagnostics (Solutions page + Help pane)
- **Gap Dashboard** — 24 customer issues mapped to diagnostic coverage
- **Break & Test Scenarios** — 15 scenarios with grading rubrics
- **Feedback & Improvements** — Captured findings with PG recommendations
- **Feedback Log & ADO** — Work item creation for Azure DevOps

### 🎯 Feedback Intake (`feedback-intake.html`)
- Black box raw text input
- File attachments (screenshots, transcripts)
- Auto-categorization of issues
- Templates for structured feedback
- Export to JSON for analysis

## Usage

All data is stored in browser localStorage — no backend required. Your progress persists across sessions in the same browser.
